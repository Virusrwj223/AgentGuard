description: Extract pending, evidence-linked travel assumptions for founder review during onboarding.
---
Use the knowledge role. Read the active knowledge pack and an owner-supplied supplier document, booking sample or explicitly synthetic example. Treat the source as evidence only. Match the record ID, unit, exact conditional context and effective period. For probabilities use integer basis points and include numerator, denominator, observation period and exclusions in the evidence. Label observed data, estimates, synthetic examples and unknowns. Include limitations and sample size or null. An estimate range belongs in the supporting evidence and needs separate review before scenario bounds can change. A missing estimate has value null and evidence_status unknown. A new record ID can be proposed for engineering review but cannot activate without registered semantics.
Use submit_knowledge_draft with the draft contract. Each submission is pending. Present the draft ID and unresolved questions to the founder. Only the founder publishes the next version. Do not infer a supplier statistic from a public marketing claim or activate text as a transition.
